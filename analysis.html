การวิเคราะห์ปัญหาเว็บไซต์ CSTU (Mobile)

🔴 ปัญหาที่ 1: Visual Hierarchy ไม่ชัดเจน
ปัญหา:
หน้าแรกของเว็บไซต์ CSTU บนมือถือขาด Visual Hierarchy ที่ชัดเจน ขนาด Font ของหัวข้อและเนื้อหาใกล้เคียงกันเกินไป ทำให้ผู้ใช้ไม่สามารถระบุจุดสำคัญได้ทันที
ทฤษฎีที่อ้างอิง:
Gestalt Principle — Law of Prägnanz: ผู้ใช้มองหา pattern ที่ชัดเจนที่สุด เมื่อไม่มี hierarchy ที่ชัด สมองต้องทำงานหนักขึ้น / Fitts' Law: ปุ่มและลิงก์ที่มีขนาดเล็กและอยู่ชิดกันทำให้ใช้งานยากบนหน้าจอมือถือ
การแก้ไข:
ออกแบบใหม่โดยใช้ Type Scale ที่ชัดเจน (H1: 24px, H2: 18px, Body: 14px) และเพิ่ม white space เพื่อสร้าง breathing room ให้แต่ละ section
🔴 ปัญหาที่ 2: Color Contrast ต่ำกว่ามาตรฐาน
ปัญหา:
สีของข้อความและพื้นหลังในส่วน Navigation และเนื้อหาหลักมี Contrast Ratio ต่ำกว่ามาตรฐาน ทำให้ผู้ที่มีความบกพร่องทางสายตา (Visual Impairment) อ่านได้ยาก
ทฤษฎีที่อ้างอิง:
WCAG 2.1 Accessibility Guidelines: กำหนดให้ Normal text ต้องมี Contrast Ratioอย่างน้อย 4.5:1 (AA level) และ Large text อย่างน้อย 3:1 / Human Factors: ผู้ใช้ประมาณ 8% ของผู้ชายมีภาวะ Color Vision Deficiency
การแก้ไข:
ใช้สีข้อความ #1A1A1A บนพื้น #FFFFFF (Contrast Ratio 18.1:1) และสีขาวบน #FF6B35 สำหรับปุ่ม (Contrast Ratio 3.8:1) ผ่านมาตรฐาน WCAG AA สำหรับ Large text
